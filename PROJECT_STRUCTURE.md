# 📁 Структура проекта Time Tracker Bot

> Дата последнего обновления: 17.02.2026

## 🎯 Назначение проекта

Telegram бот для учета рабочего времени сотрудников с интеграцией Google Sheets и WebApp интерфейсом.

---

## 📂 Файловая структура

### **Backend (Python - Telegram Bot)**

#### Главные файлы:
- **`main.py`** - Главный файл бота, обрабатывает все Telegram события
  - Middleware авторизации и автоматической привязки
  - Обработчики команд (/start, /update, /setup_checkin)
  - Обработка WebApp данных (через Reply Keyboard)
  - Централизованное логирование

- **`sheets_manager.py`** - Управление Google Sheets
  - Атомарная запись логов (защита от race conditions)
  - Автоматическое создание ежемесячных листов
  - Синхронизация списка сотрудников между главной таблицей и отчетами

- **`webhook_server.py`** - FastAPI сервер для WebApp
  - `/api/config` - получение списка сотрудников и ролей
  - `/api/upload` - временное хранение фото
  - `/api/checkin` - основной обработчик отметок из WebApp
  - `/api/claim` - безопасная привязка Telegram ID

#### Вспомогательные файлы:
- **`validators.py`** - Общая логика валидации подписи Telegram WebApp
- **`make_token.py`** - Утилита для первичной генерации OAuth токена
- **`image_uploader.py`** - (Legacy) Загрузка на ImgBB

## 🔄 Workflow работы системы

### 1. **Идентификация**
При первом входе бот пытается автоматически привязать пользователя по username. Если не удается, открывается `claim flow` в WebApp.

### 2. **Отметка времени**
1. Пользователь открывает WebApp.
2. Делает фото (селфи).
3. Данные уходят на `webhook_server.py`.
4. Сервер пишет строку в Google Sheets и пересылает отчет в Telegram-группу команды.
