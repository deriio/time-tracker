# Инструкция для Пользователей и Администраторов

Telegram бот для учета рабочего времени.

---

## 👨‍💼 Для Сотрудников

**Как отметиться (Приход/Уход):**
1.  Просто **отправьте фотографию** (селфи) в чат с ботом.
2.  Бот автоматически распознает вас по вашему Telegram Username (@username).
3.  Ваше время и фото будут записаны в таблицу.

*Если бот пишет "Access denied" — убедитесь, что у вас установлен Username в настройках Telegram, и сообщите его администратору.*

---

## 👩‍💻 Для Администраторов

### 1. Добавление Новых Сотрудников
1.  Откройте файл **MASTER_TEMPLATE** на Google Диске.
2.  Перейдите на вкладку **Config_Users**.
3.  Добавьте сотрудника:
    *   Колонка A: **ФИО** (как будет в отчете)
    *   Колонка B: **Telegram Username** (без @, например `ivan_ivanov`)
4.  В боте отправьте команду:
    `/update`
5.  Бот ответит `✅ Success`. Теперь сотрудник может отмечаться.

### 2. Ежемесячный Отчет
*   Бот создает новый файл (например, `Timesheet_January_2026`) **автоматически**, когда кто-то отправляет первое фото в новом месяце.
*   Бот **автоматически** обновляет даты в шапке таблицы под текущий месяц. Вам не нужно ничего менять вручную.

### 3. Техническое обслуживание (Важно)
Бот использует файл `token.json` для доступа к Диску.
Если бот перестал работать или пишет про "ошибку авторизации":
1.  Запустите на сервере команду `python make_token.py`.
2.  Пройдите пере-авторизацию в браузере.
