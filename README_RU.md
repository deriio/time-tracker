# Telegram Бот для Учета Времени (Check In/Out)

Надежный бот для учета рабочего времени сотрудников. Фиксирует приход/уход по фото, сохраняет данные в Google Таблицы, автоматически создает отчеты за месяц и обновляет заголовки дат.

## Возможности
*   **Фото-фиксация**: Сотрудник отправляет фото для отметки.
*   **Интеграция с Google Sheets**: Записи сохраняются в ежемесячный отчет (например, `Timesheet_December_2025`).
*   **Автоматическое управление**:
    *   Бот сам создает файл на новый месяц, копируя `MASTER_TEMPLATE`.
    *   **Автоматически исправляет даты** в шапке таблицы под текущий месяц (1-31 число).
*   **Динамическое управление пользователями**:
    *   Список сотрудников берется из вкладки `Config_Users` в Master Template.
    *   Команда `/update` позволяет обновить список сотрудников без перезапуска бота.
*   **Работа от имени Владельца (OAuth)**: Решает проблему квот Google Drive, позволяя боту создавать файлы без ограничений (использует 15 ГБ вашего диска).

## Установка и Настройка

### 1. Подготовка
Вам понадобится проект в Google Cloud Console и **OAuth 2.0 Client ID** (тип Desktop App).

### 2. Конфигурация (.env)
Создайте файл `.env` на основе примера:
```ini
BOT_TOKEN=ваш_токен_бота
GOOGLE_JSON_PATH=credentials.json  # Имя файла OAuth Client ID
DRIVE_FOLDER_ID=id_папки_диска
TEMPLATE_FILE_ID=id_файла_шаблона
ADMIN_IDS=11111111,22222222
```

### 3. Авторизация (Важно!)
Чтобы бот мог создавать файлы от вашего имени:
1.  Скачайте `credentials.json` из Google Cloud Console и положите в папку бота.
2.  Запустите скрипт настройки (один раз):
    ```bash
    python make_token.py
    ```
3.  Перейдите по ссылке, залогиньтесь под аккаунтом владельца папки Google Drive.
4.  После успешного входа создастся файл `token.json`.

### 4. Запуск
```bash
python main.py
```
