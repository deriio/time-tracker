# Руководство по развертыванию (OAuth 2.0)

Это руководство поможет вам настроить бота для работы **от имени вашего Google Аккаунта**. Это наиболее надежный способ, исключающий ошибки с квотами (`storageQuotaExceeded`), так как бот использует ваше личное хранилище (15 ГБ+).

---

## ШАГ 1: Создание Проекта и Ключей в Google Cloud

1.  Зайдите в [Google Cloud Console](https://console.cloud.google.com/).
2.  Создайте новый проект (или выберите существующий).
3.  **Включите API**:
    *   В поиске найдите **Google Drive API** -> Enable.
    *   В поиске найдите **Google Sheets API** -> Enable.

4.  **Настройте Экран Согласия (OAuth Consent Screen)**:
    *   Меню слева: **APIs & Services** -> **OAuth consent screen**.
    *   Выберите **External** (Внешний) -> **CREATE**.
    *   Заполните обязательные поля:
        *   **App Name**: `TimeTrackingBot`
        *   **User support email**: Ваш email.
        *   **Developer contact info**: Ваш email.
    *   Нажмите **SAVE AND CONTINUE** (везде далее можно просто нажимать Save).
    *   В разделе **Test Users** (Обязательно!):
        *   Нажмите **ADD USERS**.
        *   Введите **Ваш Email** (на котором находится папка Диска).
        *   Нажмите Save.

5.  **Получите Ключи (Credentials)**:
    *   Меню слева: **Credentials**.
    *   Нажмите **+ CREATE CREDENTIALS** -> **OAuth client ID**.
    *   **Application type**: Desktop app.
    *   **App name**: Client 1 (можно не менять).
    *   Нажмите **CREATE**.
    *   **Скачайте JSON-файл**, нажав на иконку загрузки (стрелка вниз).
    *   **Переименуйте файл в `credentials.json`** и положите в папку с ботом.

---

## ШАГ 2: Подготовка Папок и Шаблона

1.  **На Google Диске**:
    *   Создайте папку (например, `Учет Времени`).
    *   Скопируйте `DRIVE_FOLDER_ID` (часть ссылки после /folders/).
2.  **Шаблон**:
    *   Положите файл `MASTER_TEMPLATE` внутрь этой папки.
    *   Скопируйте его `TEMPLATE_FILE_ID` (часть ссылки между /d/ и /edit).

---

## ШАГ 3: Настройка Бота (.env)

В папке бота переименуйте `.env.example` в `.env` и укажите данные:
```ini
BOT_TOKEN=ваш_телеграм_токен
GOOGLE_JSON_PATH=credentials.json
DRIVE_FOLDER_ID=ваш_id_папки
TEMPLATE_FILE_ID=ваш_id_шаблона
ADMIN_IDS=ваш_телеграм_id (цифры)
```

---

## ШАГ 4: Первая Авторизация (Генерация Токена)

Этот шаг нужно выполнить **один раз** при установке (или если токен слетит).

1.  Откройте терминал в папке с ботом.
2.  Запустите скрипт генерации токена:
    ```bash
    python make_token.py
    ```
3.  В консоли появится длинная ссылка. **Скопируйте её и вставьте в браузер**.
4.  Войдите в тот Google Аккаунт, где лежит Папка.
5.  Если появится предупреждение "Google hasn’t verified this app", нажмите:
    *   **Advanced** (Дополнительно) -> **Go to TimeTrackingBot (unsafe)**.
6.  Нажмите **Allow (Разрешить)** на всех экранах (доступ к Диску и Таблицам).
7.  В папке бота появится файл `token.json` (а в консоли будет написано "Success").

---

## ШАГ 5: Запуск

Теперь можно запускать основного бота:
```bash
python main.py
```

Бот будет работать от вашего имени. Каждый месяц он будет:
1.  Создавать новую таблицу (копию шаблона).
2.  Автоматически переименовывать её (например, `Timesheet_January_2026`).
3.  Автоматически проставлять правильные даты (1-31) в шапке отчета.
