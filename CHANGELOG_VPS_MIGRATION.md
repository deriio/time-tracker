## 🏗️ Архитектура решения

### Двухуровневая очистка фото:

1. **Immediate Cleanup** (main.py):
   - Удаление сразу после успешной отправки в Telegram
   - Минимизирует использование диска
   - Fallback на TTL при ошибке

2. **Background Cleanup** (webhook_server.py):
   - Фоновая задача каждые 60 секунд
   - Удаляет фото старше 5 минут
   - Защита от "забытых" файлов при сбоях

### Production Stack:

```
Internet (443/80)
    ↓
Nginx (Reverse Proxy + SSL)
    ↓
    ├─→ /api → FastAPI (127.0.0.1:8000)
    └─→ /photos → Static Files (TTL: 5 min)
         ↓
    Photos Directory
    (Auto-cleanup every 60s)
```

## 🚀 Следующие шаги для пользователя

1. **Подготовить VPS**:
   - Получить VPS с Ubuntu 22.04
   - Настроить DNS для домена

2. **Загрузить credentials**:
   - Скопировать credentials.json на VPS
   - Скопировать token.json на VPS
   - Скопировать oauth_credentials.json на VPS

3. **Запустить развертывание**:
   ```bash
   ./deploy/scripts/deploy.sh
   ```

4. **Настроить Nginx и SSL**:
   - Отредактировать домен в конфигурации
   - Получить SSL сертификат

5. **Обновить .env**:
   - Установить WEBHOOK_SERVER_URL с доменом

6. **Проверить работу**:
   - Протестировать check-in/out
   - Проверить автоочистку фото

## 📝 Примечания

- Все изменения обратно совместимы

- Миграция не требует изменений в frontend (GitHub Pages)
